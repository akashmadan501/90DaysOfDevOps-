# Linux Commands Cheatsheet 

- `ls` - list all the files and directories
- `cd ..` - to navigate one dir back
- `cd -` - to navigate to previos directory
- `netstat -a` - Show network connectins with  tcp and udp ports
- `ps`  - to display processes running
- `vim` - to edit file
- `kill PID` - to kill  process with specifi PID
- `pgrep PROCESS_NAME` - to get PID of process by name
- `btop` - to better representation of processes and system metrics
- `wc FILE_NAME` - to get word count
- `head/tail FILE_NAME` - Display first/last 10 lines of file (usually used to see logs)
- `du -h` - show file/folder size on disk  
- `df -h` - Display free disk available all over machine
- `free -h` - Display RAM usage
- `ifconfig/ip a` - Display all network interfaces with IP addresses.
- `traceroute host` - Traces network path.
- `wget url` - Download files from internet using terminal.
- `host domain` - Displays DNS IP address for domain.
- `nslookup domain` - Display IP address of domain.
- `ps -aux | grep 'brave'` - Display process related to what we searched
